Isi

Delapan bab, satu aplikasi.

Bab-bab ini mengikuti pekerjaan yang biasanya terpencar di beberapa aplikasi: dari daftar host sampai install.

  1. 01Hosts dan terminalDaftar server, autentikasi, terminal lokal, tunnel, key, dan snippet.
  2. 02Dashboard dan operasiCPU, RAM, disk, proses, service, cron, dan log dari satu layar.
  3. 03Database dan backup23 engine, pencarian per kolom, SQL, dump terjadwal, dan restore.
  4. 04SFTP dan editorDua panel file, transfer paralel, editor bawaan, dan buka dengan app lokal.
  5. 05Docker dan server lokalContainer per proyek Compose, plus Apache, PHP, MySQL, PostgreSQL, dan MongoDB di komputermu.
  6. 06Tim dan sinkronisasiBagikan host terenkripsi, undang lewat email, dan sinkronkan lewat Google Drive.
  7. 07KeamananArgon2id, XChaCha20-Poly1305, Touch ID, Windows Hello, dan sumber terbuka.
  8. 08InstallDMG, Setup.exe, atau AppImage. Langkah pertama dan catatan rilis.

Bab 01Hosts

Semua server, satu daftar.

Host disusun per grup, dengan status dan waktu connect terakhir. Pilih beberapa host, lalu buka satu tab untuk masing-masing.

Klik dua kali untuk connect, atau pilih beberapa host dan jalankan Connect all. Autentikasi bisa memakai password, SSH key, atau SSH agent. Jump host, proxy SOCKS5/HTTP, agent forwarding, startup snippet, dan env var diatur per host.

Terminal lokal berjalan di tab yang sama: zsh di Mac, PowerShell, CMD, atau WSL di Windows. Tema terminal bisa diganti, dan alamat server bisa disamarkan saat berbagi layar.

Bab 02Dashboard

Pantau dan urus tanpa pindah aplikasi.

CPU, RAM, disk, uptime, dan jaringan tiap server diperbarui tiap 5 detik. Proses, service, cron, dan log ada di layar yang sama.

Server yang hampir penuh atau mati ditandai, dengan notifikasi desktop. Kamu bisa menjalankan satu perintah di banyak server secara paralel dan melihat exit code, output, serta durasi per server.

Panel Info server menampilkan spesifikasi, grafik CPU, RAM, dan jaringan tiap 3 detik. Tidak ada agen yang perlu dipasang di server.

Bab 03Database

Database dan backup di layar yang sama.

Telusuri tabel, cari per kolom, jalankan SQL, lalu jadwalkan dump tanpa membuka browser.

MySQL, MariaDB, PostgreSQL, SQL Server, SQLite, Redis, MongoDB, ClickHouse, dan 15 layanan lain. Koneksi bisa langsung, TLS, lewat tunnel SSH, atau proxy.

Backup berjalan lewat SSH: dump dijalankan di server dan hasilnya tersimpan terkompres di komputermu. Jadwalkan tiap hari atau minggu, simpan sejumlah backup terakhir, dan pulihkan dari daftar.

Bab 04SFTP

File server, dua panel.

Komputermu di kiri, server di kanan. Seret file atau folder, lalu lihat progres dan kecepatan per transfer.

Upload dan download berjalan paralel. Folder baru, rename, hapus, dan chmod tersedia dari panel yang sama. Fingerprint server dicek dengan known_hosts.

Klik dua kali file teks untuk membuka editor bawaan: nomor baris, pencarian, dan simpan dengan Cmd/Ctrl+S. Kalau file berubah di server sebelum kamu menyimpan, Zterm memberi peringatan. File juga bisa dibuka di VS Code, Sublime, Notepad++, atau app lain, lalu di-upload otomatis setiap kali kamu menyimpan.

Bab 05Docker

Docker dan server lokal, satu kendali.

Container di server mana pun lewat SSH, plus Apache, PHP, dan database di komputermu.

Container dikelompokkan per proyek Compose. Panel detail menampilkan CPU dan RAM live, port yang bisa diklik, env, mount, network, dan log. Satu klik membuka terminal di dalam container. Compose bisa di-up, restart, stop, atau down per proyek.

Server lokal menjalankan Apache atau Nginx dengan PHP 8.4, plus MySQL 8.4, PostgreSQL 17, dan MongoDB 8. Komponen diunduh saat pertama dipakai. Port bisa diatur, hanya mendengarkan di 127.0.0.1, dan semua berhenti saat app ditutup.

Start, stop, restart, hapus
Detail
CPU/RAM, port, env, mount, network, log
Shell

Compose
Up, restart, stop, down; bersihkan image dan volume

Apache atau Nginx + PHP 8.4
Database lokal

Unduh
Hanya komponen yang dipakai; Apache bawaan macOS bisa dipakai

Bab 06Tim

Satu tim, satu daftar host.

Admin membagikan host terenkripsi lewat email. Anggota klik Gabung tim, lalu host muncul di Zterm mereka.

Host, password, dan SSH key dienkripsi end-to-end dengan kunci tim yang hanya dimiliki anggota. Google menyimpan ciphertext dan alamat email yang diundang. Saat admin mengubah host, semua anggota ikut terupdate. Saat anggota dikeluarkan, akses dicabut dan kunci tim diganti.

Vault disinkronkan ke folder appdata Google Drive milikmu. Login di Mac atau PC lain, masukkan master password, dan daftar host kembali.

Lewat email Google; tanpa akun Zterm
Enkripsi
Host, password, SSH key; kunci tim hanya di anggota
Sync
Google Drive appdata, otomatis setelah perubahan
Perangkat
Mac dan Windows memakai vault yang sama; Linux beta untuk hosts, terminal, keychain, snippets

Akses Drive
Appdata dan file tim yang dibuat atau dipilih lewat Zterm

Bab 07Keamanan

Kunci ada di perangkatmu.

Zterm tidak punya akun dan tidak punya server. Vault dienkripsi sebelum meninggalkan perangkat.

Master password tidak pernah disimpan atau dikirim ke mana pun.

Enkripsi bekerja di perangkat. Kunci diturunkan dari master password, lalu dipakai untuk membuka vault. Tidak ada jalur pemulihan dari pihak Zterm karena tidak ada salinan master password yang disimpan.

  1. Enkripsi vault

    Argon2id menurunkan kunci dari master password. XChaCha20-Poly1305 mengenkripsi isi vault.

  2. Tanpa server Zterm

    Tidak ada akun, analitik, iklan, atau pelacakan. Data tidak dikirim ke server pengembang.

  3. Kunci perangkat

    Touch ID di Mac dan Windows Hello di Windows. Kunci cepat dengan Shift+Cmd+L atau Ctrl+Shift+L.

  4. Google Drive

    Hanya folder appdata dan file tim yang dibuat lewat Zterm. Google tidak bisa membaca isi terenkripsi.

  5. Sumber terbuka

    Lisensi MIT. Kode sumber tersedia di GitHub untuk diperiksa siapa saja.

App belum dinotarisasi Apple dan belum ditandatangani sertifikat Windows. Langkah membuka app ada di bab Install.

Bab 08Install

Pilih platform, lalu mulai.

Versi 1.0.1 tersedia untuk macOS, Windows, dan Linux beta. Semua build memakai inti Rust yang sama.

Cara install di Mac

  1. Unduh file .dmg, buka, lalu seret Zterm ke folder Applications.
  2. App belum dinotarisasi Apple. Saat pertama dibuka, buka System Settings > Privacy & Security, lalu klik Open Anyway.
  3. Kalau macOS bilang app rusak, jalankan ini sekali di Terminal:
xattr -cr "/Applications/Zterm.app"
Unduh DMG untuk macOS

DMG berisi build universal untuk Apple Silicon dan Intel. macOS 15 atau lebih baru.

Cara install di Windows

  1. Unduh Setup.exe: versi x64 untuk kebanyakan PC, atau ARM64 untuk PC ARM seperti Snapdragon.
  2. App belum ditandatangani sertifikat berbayar. Kalau muncul Windows protected your PC, klik More info > Run anyway.
  3. Ikuti installer. Tidak butuh hak admin. Setelah selesai, buka Zterm dari Start Menu.
Unduh Setup x64 Unduh Setup ARM64

Windows 10 dan 11. Hapus kapan saja lewat Settings > Apps. Vault dan pengaturan tetap aman.

Cara install di Linux (beta)

  1. Unduh AppImage: x86_64 untuk kebanyakan PC, atau aarch64 untuk PC atau laptop ARM.
  2. Jadikan bisa dijalankan, lalu buka (atau klik dua kali dari file manager):
  3. Butuh distro yang cukup baru (glibc 2.39+), misalnya Ubuntu 24.04, Debian 13, atau Fedora 40.

FAQ

Pertanyaan yang sering muncul.

Jawaban singkat untuk hal yang biasanya ditanyakan sebelum install.

Benar-benar gratis?

Ya. Lisensi MIT, tanpa iklan, dan tanpa langganan.

Apakah Zterm bisa melihat password server saya?

Tidak. Semua data dienkripsi di perangkatmu dengan master password. Zterm tidak punya server, dan Google hanya menyimpan file terenkripsi yang tidak bisa dibaca tanpa master password.

Kalau lupa master password?

Vault tidak bisa dibuka. Itu konsekuensi enkripsi end-to-end. Simpan master password di tempat yang aman.

Kenapa ada peringatan saat dibuka?

App belum dinotarisasi Apple dan belum ditandatangani sertifikat Windows, karena keduanya berbayar. Kode sumbernya terbuka di GitHub untuk diperiksa siapa saja. Di Mac, buka lewat Privacy & Security > Open Anyway. Di Windows, klik More info > Run anyway. Cukup sekali.

Akses Google Drive apa yang diminta?

Hanya folder data khusus aplikasi (drive.appdata) yang tersembunyi. Untuk fitur Tim, Zterm meminta drive.file agar bisa membuat file tim dan membukanya kembali. Zterm tidak bisa melihat file lain di Drive-mu.

Bisa konek lewat proxy kantor?

Bisa. Di editor host, buka Lanjutan > Proxy, pilih SOCKS5 atau HTTP, lalu isi alamat, port, dan login jika perlu. Kamu juga bisa menjadikan server SSH sebagai proxy SOCKS lewat Port Forwarding.

Ada versi Windows?

Ada. Windows 10 dan 11, untuk PC x64 maupun ARM64. Build ini memakai inti Rust yang sama, jadi satu vault bisa dipakai di Mac dan Windows lewat sync Google Drive.

Ada versi Linux?

Ada, masih beta: AppImage untuk x86_64 dan ARM64 dengan GTK4, libadwaita, dan terminal VTE. Yang sudah berjalan: hosts, terminal SSH dan lokal, keychain, serta snippets. SFTP, Database, Docker, Dashboard, dan sync Google menyusul.

Ada bahasa Inggris?

Ada. App tersedia dalam bahasa Indonesia dan Inggris. Bahasa mengikuti sistem, atau bisa dipilih lewat menu Bahasa / Language. Pesan error dari server ikut diterjemahkan.
