Gabung tim Zterm

Kamu diundang ke tim. Pilih file tim sekali di sini, lalu host yang dibagikan admin muncul di Zterm-mu.

  1. Masuk dengan akun Google yang diundangAkun yang menerima email undangan harus sama dengan akun Google di Zterm-mu.
  2. Pilih file timNamanya berakhiran .ztermteam, ada di “Dibagikan kepada saya”.
  3. Kembali ke Zterm milikmuDi perangkatmu sendiri (bukan milik admin): Tim → Gabung tim → Cek undangan, lalu klik Gabung.

✓ File tim terpilih

Kembali ke Zterm → Tim → Gabung tim → Cek undangan.
